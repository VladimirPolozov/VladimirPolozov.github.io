# Аудио

Сюда кладутся mp3-файлы к песням. Обычно достаточно ссылки на оригинал в файле песни, но редкие/важные записи можно положить и здесь.

Правила:

- Файл не больше ~25 МБ (лимит GitHub — 100 МБ, но репозиторий лучше не раздувать).
- Имя файла: `название-песни.mp3`.
- В файле песни ссылайся так: `[Слушать](audio/название-песни.mp3)`.
- Для переноса из Telegram: `python tools/export_to_md.py result.json --copy-media`.

# Аккорды RCC Worship

Сборник аккордов к песням, которые мы играем в церкви. Один файл в `songs/` — одна песня: тональность, темп, аккорды, слова, ссылка на оригинал.

## Полезное

- [Сайт для транспонирования аккордов](https://chords.poncy.ru) — в 99% случаев транспонирует правильно.

## Поиск

Вверху слева поле поиска: вводи название песни, автора или любую строчку из текста/аккордов — найдутся все подходящие файлы.

## Песни

Список всех песен — в сайдбаре слева (только названия). Отдельные страницы по исполнителям — раздел «Исполнители».

Название, исполнители и английское название каждой песни хранятся отдельно в `tools/song_meta.py`. По ним скрипт `tools/build.py`:

- приводит заголовки песен к чистым названиям и добавляет под ними блок справки (исполнитель, оригинал, тональность);
- генерирует страницу на каждого исполнителя в `artists/`;
- пересобирает `_sidebar.md`.

Не редактируй `_sidebar.md` и `artists/` руками.

## Как добавить песню

1. Создай файл `songs/название-песни.md`
2. Первая строка — заголовок: `# Название (Автор) - Тональность`
3. Ниже — аккорды, слова, ссылка на оригинал
4. `python tools/extract_meta.py` — разместит метаданные в `tools/song_meta.py`; проверь и поправь запись при необходимости
5. `python tools/build.py` — обновит заголовки песен, страницы исполнителей и сайдбар
6. `git add . && git commit -m "добавлена песня" && git push`

## Аудио

- По умолчанию в файле песни ссылка на оригинал (YouTube).
- Редкие/важные mp3 кладутся в `audio/` (до ~25 МБ, чтобы репозиторий не раздувался) и подключаются так: `[Слушать](audio/название-песни.mp3)`.

## Развёртывание на GitHub Pages

1. Создай публичный репозиторий и запушь ветку `main` в эту папку.
2. GitHub → Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через ~минуту сайт доступен по адресу `https://<ник>.github.io/<репозиторий>/`.
4. Чтобы сбросить в чат список песен — копируй ссылки из сайдбара: у каждой песни свой постоянный URL.

## Перенос архива из Telegram

Архив был перенесён из двух каналов Telegram (`tools/migrate.py`):

1. Telegram Desktop → Настройки → Дополнительно → Экспорт истории → формат JSON.
2. Экспорты канала и группы «Оригиналы, Туториалы, Тексты» → в `channel_export/result.json` и `result_2.json`.
3. `python tools/migrate.py` — песни берутся из канала, а из группы к ним прикрепляются слова, ссылки на оригиналы и примечания (по совпадению названия).
4. Вручную сопоставленные пересылки лежат в `OVERRIDES` в `tools/migrate.py`.
5. После конвертации: `python tools/extract_meta.py` (черновик метаданных; спорные случаи поправь в `tools/song_meta.py` или `MANUAL` в `extract_meta.py`) и `python tools/build.py`.

Сырые экспорты в git не коммитятся (папка `channel_export/` в `.gitignore`).

# Аккорды RCC Worship

Сборник аккордов к песням. Один файл в `songs/` — одна песня: тональность, темп, аккорды, слова, ссылка на оригинал.

## Поиск

Вверху слева поле поиска: вводи название песни, автора или любую строчку из текста/аккордов — найдутся все подходящие файлы.

## Песни

Список всех песен — в сайдбаре слева. Он генерируется скриптом `tools/gen_sidebar.py` (не редактируй `_sidebar.md` руками).

## Как добавить песню

1. Создай файл `songs/название-песни.md`
2. Первая строка — заголовок: `# Название (Автор) - Тональность`
3. Ниже — аккорды, слова, ссылка на оригинал
4. Запусти `python tools/gen_sidebar.py`
5. `git add . && git commit -m "добавлена песня" && git push`

## Аудио

- По умолчанию в файле песни ссылка на оригинал (YouTube).
- Редкие/важные mp3 кладутся в `audio/` (до ~25 МБ, чтобы репозиторий не раздувался) и подключаются так: `[Слушать](audio/название-песни.mp3)`.

## Развёртывание на GitHub Pages

1. Создай публичный репозиторий и запушь ветку `main` в эту папку.
2. GitHub → Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Через ~минуту сайт доступен по адресу `https://<ник>.github.io/<репозиторий>/`.
4. Чтобы сбросить в чат список песен — копируй ссылки из сайдбара: у каждой песни свой постоянный URL.

## Перенос архива из Telegram

1. Telegram Desktop → Настройки → Дополнительно → Экспорт истории сообщений → выбери канал, формат JSON (и HTML/медиа).
2. Положи `result.json` в корень и запусти `python tools/export_to_md.py result.json` (комментарии-ответы прикрепятся к песне цитатами).
3. После грубой конвертации пройдись по `songs/` руками или с помощью ИИ: поправить названия, слить дубликаты, добавить слова и ссылки на оригиналы.

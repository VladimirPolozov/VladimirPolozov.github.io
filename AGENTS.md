# AGENTS.md — инструкции по репозиторию

Репозиторий: `VladimirPolozov/VladimirPolozov.github.io` (ветка `main`, GitHub Pages).
Сайт — сборник аккордов церковных песен: docsify на статике без сборки.

## Что это

- `index.html` — точка входа: подключает `tools/transpose-core.js` и `tools/transpose.js` **до** CDN docsify@4, настраивает `window.$docsify` (сайдбар, поиск, `breaks: true`).
- Один файл `songs/<slug>.md` — одна песня.
- 237 песен, 78 исполнителей (`artists/`), 6 категорий (`categories/`).

## Структура

- `songs/*.md` — песни. В начале: frontmatter `key:`, затем `# Название`, затем блок сведений (`> **…:**`), затем аккорды и слова.
- `artists/*.md` + `artists/index.md` — страницы исполнителей (заголовок `# Имя`, список песен со ссылками).
- `categories/*.md` + `categories/index.md` — страницы категорий.
- `_sidebar.md` — сайдбар docsify (главная, исполнители, категории, песни).
- `tools/` — скрипты (см. ниже).
- `audio/` — редкие mp3 (до ~25 МБ), подключаются `[Слушать](audio/файл.mp3)`.
- `channel_export/` — сырые экспорты Telegram, в git не коммитятся (`.gitignore`).

## Формат песни

```markdown
---
key: A
---
<!-- tg: msg <id> | <дата> -->

# Название песни

> **Исполнитель:** [Bethel Music](/artists/bethel-music)
> **Категория:** [Поклонение](/categories/poklonenie), [Прославление](/categories/proslavlenie)
> **Оригинальное название:** Waymaker
> **Тональность:** A
> **Размер:** 6/8
> **Темп:** 118
```

- Поле «Категория» должно идти **до** «Тональность» (транспонирование затрагивает блок от «Тональность»).
- Аккорды — строки вида `D | A | E | F#m |`.
- Части песен (Куплет, Припев, Вступление, Проигрыш, Окончание, Предприпев, Тэг, Поворот, Бридж, Рэп) — русские, жирным `**…**`, без двоеточия, цифра в конец («Куплет 1»), с большой буквы. См. `tools/normalize_sections.js` (был удалён после применения).

## Категории

Буквы разметки: **P** — прославление, **W** — поклонение, **M** — средний темп, **C** — детские, **O** — другое, **J** — еврейские. Песня может быть в нескольких категориях.

Порядок отображения: Поклонение, Прославление, Средний темп, Детские, Еврейские, Другое.

## Скрипты

- `tools/build_categories.py` — **актуальный**. Читает поле `**Категория:**` из песен, пересобирает `categories/*.md` и `categories/index.md`. Запуск: `python tools/build_categories.py`.
- `tools/transpose-core.js` — ядро транспонирования (аккорды, тональности, DOM). `transposeKeyTextNodes` — транспонирует только узлы от «Тональность»/«Key:», чтобы не задеть «Исполнитель:».
- `tools/transpose.js` — плагин docsify: кнопки −/0/+, средняя показывает текущую тональность буквой (`G#`, `A`, `Bbm`…) и сбрасывает при клике; выбранная тональность пишется в `?key=` в адресе (без localStorage), переход на другую песню сбрасывает транспонирование (если в URL нет `?key=`); при открытии ссылки с `?key=` песня сразу транспонируется в неё.
- `tools/test_transpose.js` — тесты корпуса (`node tools/test_transpose.js`): прогонять перед пушем, если менялся `transpose-core.js` или логика определения/сдвига аккордов. Для чисто визуальных/CSS-правок в `transpose.js` (без изменения разбора аккордов) тест можно пропустить — он проверяет, что не-аккордовые строки не меняются.
- `tools/song_meta.py`, `tools/build.py`, `tools/extract_meta.py`, `tools/migrate.py`, `tools/export_to_md.py`, `tools/gen_sidebar.py` — **устаревший Python-конвейер** (README о нём устарел). Песни правятся вручную/разовыми скриптами; `build.py` перезапишет блоки сведений (уберёт ссылки на исполнителей, «Оригинальное название», «Размер», «Темп», «Категория») — не запускать.

## Конвенции и история решений

- Транспонирование сбрасывается в 0 при каждом переходе на другую песню (localStorage больше не используется).
- Тональность — в YAML-frontmatter `key:`; DOM-парсинг blockquote — fallback (`captureBaseKey` берёт текст после «Тональность»).
- «Оригинал» в метаданных → «Оригинальное название»; «3/4», «6/8» → «Размер»; bpm (обычно 60–148) → «Темп».
- Имя исполнителя в сведениях — ссылка на страницу `/artists/<slug>`; мульти-исполнители — через запятую, каждый со ссылкой.
- Категория в сведениях — ссылка на `/categories/<slug>`.
- Ссылки в сайдбаре/категориях: песни — `/songs/<file>.md`, исполнители/категории — `/artists/<slug>` / `/categories/<slug>`.
- Разовые скрипты удаляются из репозитория до коммита.
- Коммиты на русском. Пуш в `main` деплоит GitHub Pages.
- В консоли PowerShell кириллица в выводе git/Select-String искажается — для чтения UTF-8 лучше использовать node-скрипты.

## Типичные задачи

- **Добавить категорию песне**: вставить/поправить строку `> **Категория:** […](/categories/…)`, затем `python tools/build_categories.py`.
- **Проверить перед пушем** (если трогали логику аккордов): `node tools/test_transpose.js`.
